# Folder Automation

A lightweight Windows desktop application for automatically organizing files into categorized folders based on their file types.

Folder Automation is designed to eliminate repetitive manual file organization. Select a folder, preview how its files will be categorized, and let the application create the appropriate folders and move the files automatically.

## Overview

Managing folders containing mixed files can quickly become repetitive.

For example, a folder may contain:

- `.jpg`, `.png`, `.jpeg` images
- `.mp4`, `.mkv` videos
- `.mp3`, `.wav` audio files
- `.pdf`, `.docx`, `.pptx` documents
- `.xlsx`, `.csv` spreadsheets
- `.zip`, `.rar` archives

Folder Automation analyzes the files and organizes them into dedicated folders within the selected directory.
